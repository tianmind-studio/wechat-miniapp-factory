# 产品说明 / Product Brief

## 名称 / Name

骰盅组局 (Dice Party)

## 简介 / Description

一款用于聚会场景的小游戏小程序：选题 → 摇骰 → 执行。适合朋友聚会、团建破冰、桌游助手等场景。

A party game Mini Program: pick a topic → roll dice → execute. Suitable for friend gatherings, team building, and board game assistance.

## 核心功能 / Core Features

1. **题目库**：真心话、大冒险、谁最可能三类题目（示例数据）
2. **摇骰动画**：模拟骰子滚动，增加仪式感
3. **玩家轮转**：根据骰子点数决定执行者

## 目标用户 / Target Users

- 朋友聚会场景
- 团建破冰活动
- 桌游爱好者

## 架构 / Architecture

- 纯前端 + 本地 mock 数据
- 无后端依赖，便于快速预览和学习
- 可扩展为 CloudBase 版本
