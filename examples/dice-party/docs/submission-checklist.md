# 提审清单 / Submission Checklist

## 基础配置 / Basic Setup

- [ ] 在 `project.config.json` 中填入正式 AppID
- [ ] 确认 `app.json` 中的 navigationBarTitleText 和名称一致
- [ ] 确认 `sitemap.json` 配置符合索引需求

## 内容准备 / Content

- [ ] 替换 `utils/mock-data.js` 中的示例题目为正式内容
- [ ] 确认所有题目内容合规（无政治、暴力、色情、诱导等）
- [ ] 确认首页有真实可用的功能入口

## 类目与资质 / Category & Qualification

- [ ] 确认服务类目（建议：生活服务 > 便民服务）
- [ ] 确认无需特殊资质（无抽奖、无支付、无 UGC）
- [ ] 如有 UGC 功能需接入内容安全 API

## 隐私合规 / Privacy

- [ ] 添加隐私政策说明（可用微信隐私协议模板）
- [ ] 本示例不收集用户信息，但正式版需声明
- [ ] 如使用地理位置、相册等权限需说明用途

## 审核路径 / Reviewer Path

1. 打开小程序，进入题目选择页
2. 选择任意分类，看到题目卡片
3. 点击"继续摇骰"进入摇骰页
4. 点击"摇骰子"看到动画和结果
5. 查看结果页，可重新摇或换题

## 审核备注建议 / Submission Note Draft

```
本小程序是聚会游戏工具，主要功能为选题和摇骰决定执行者。

审核路径：
1. 首页选择题目分类（真心话/大冒险/谁最可能）
2. 点击"继续摇骰"进入摇骰页
3. 点击"摇骰子"查看动画和被选中的玩家
4. 在结果页可重新摇或换题

无需登录，无支付功能，无 UGC 内容。
```

- [ ] 真机预览无异常
