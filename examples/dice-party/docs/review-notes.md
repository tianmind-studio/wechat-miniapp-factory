# 审核备注 / Review Notes

## 审核员路径 / Reviewer Path

### 中文版

1. 打开小程序，直接进入题目选择页（无需登录）
2. 点击任意分类按钮（真心话/大冒险/谁最可能）
3. 查看随机出现的题目卡片
4. 点击"换一道"可更换题目
5. 点击"继续摇骰"进入摇骰页
6. 点击"摇骰子"，骰子动画后自动选中一位玩家
7. 自动跳转到结果页，显示被选中的玩家和题目
8. 点击"重新摇"返回摇骰页，或点击"换一题"回到首页

### English Version

1. Open the Mini Program, enter topic selection page (no login required)
2. Tap any category button (Truth/Dare/Most Likely)
3. View the randomly displayed topic card
4. Tap "换一道" to change topic
5. Tap "继续摇骰" to enter the dice rolling page
6. Tap "摇骰子" to roll, animation plays and a player is selected
7. Auto-navigate to result page showing selected player and topic
8. Tap "重新摇" to roll again, or "换一题" to return to home

## 功能说明 / Feature Description

- **题目选择**：三种题目类型，随机抽取，可手动更换
- **摇骰决定**：骰子动画，根据点数决定玩家
- **结果展示**：显示被选中的玩家、题目内容和骰子点数

## 声明 / Disclaimer

- 这是示例骨架，所有题目为 mock 数据
- 无真实用户数据收集
- 无支付功能
- 无 UGC 内容上传
