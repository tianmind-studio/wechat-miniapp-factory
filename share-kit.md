## English

I open-sourced `wechat-miniapp-factory`, a Codex / Claude-compatible skill workflow for building WeChat Mini Programs.

It does more than generate code:

- scaffolds a native Mini Program starter
- adds CloudBase-ready structure
- validates project files
- prepares submission notes
- runs a reviewer-style preflight check for common WeChat rejection risks

Useful if you build WeChat Mini Program prototypes, student projects, or agentic coding workflows that need real handoff artifacts.

Repo:
https://github.com/tianmind-studio/wechat-miniapp-factory

Feedback and issues are welcome.
